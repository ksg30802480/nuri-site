렌탈 계약부터 청구, 미수금까지
내 PC에서 한 번에

거래처·기기·계약을 등록하면 월 청구서와 거래명세서가 만들어지고, 카운터 매수 청구와 AS 접수까지 한 곳에서 관리합니다. 인터넷 없이 내 PC에서 빠르게 동작합니다.

주요 기능

거래처 · 기기 · 계약

설치 기기와 계약 조건(월 임대료, 기본 매수, 초과 단가)을 거래처별로 관리합니다.

월 청구 · 통합청구

정액·카운터·혼합 청구를 계산해 청구서를 만들고, 여러 계약을 한 번에 묶어 청구합니다.

명세표 인쇄 · PDF 메일

거래명세표를 A4에 인쇄하거나 PDF로 거래처에 바로 메일 발송합니다. 직인도 등록할 수 있습니다.

AS 접수 · 카운터

AS 요청을 접수하고 처리 내역을 기록합니다. 카운터 입력과 자동 수집 연동도 지원합니다.

판매 · 매입 · 수금

소모품 판매와 매입, 입금·지급을 등록하면 거래처별 미수금이 자동 계산됩니다.

네트워크 공유 · 자동 백업

같은 사무실의 다른 PC·휴대폰에서도 접속할 수 있고, 매일 자동 백업되며 언제든 복원합니다.

설치 방법

  1. 내려받기 — 위의 [무료 체험판 내려받기]를 눌러 OA_Rental_Setup.exe를 받습니다.
  2. 설치 실행 — 받은 파일을 실행합니다. Windows 보안 경고가 나오면 [추가 정보] → [실행]을 누릅니다.
  3. 처음 설정 — 설치가 끝나면 브라우저가 열립니다. 회사명과 로그인 아이디·비밀번호를 정하면 바로 사용할 수 있습니다.
  4. 다른 PC에서 접속(선택) — [환경설정 → 네트워크 공유]에서 허용하면 같은 사무실의 다른 PC에서 접속할 수 있습니다.

새 버전도 같은 방법으로 설치하면 되며, 입력한 자료(C:\ProgramData\OARental)는 그대로 유지됩니다.
