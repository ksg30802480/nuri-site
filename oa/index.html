주요 기능

거래처 · 기기 · 계약

설치 기기와 계약 조건(월 임대료, 기본 매수, 초과 단가)을 거래처별로 관리합니다.

월 청구 · 통합청구

정액·카운터·혼합 청구를 계산해 청구서를 만들고, 여러 계약을 한 번에 묶어 청구합니다.

명세표 인쇄 · PDF 메일

거래명세표를 A4에 인쇄하거나 PDF로 거래처에 바로 메일 발송합니다. 직인도 등록할 수 있습니다.

AS 접수 · 카운터

AS 요청을 접수하고 처리 내역을 기록합니다. 카운터 입력과 자동 수집 연동도 지원합니다.

판매 · 매입 · 수금

소모품 판매와 매입, 입금·지급을 등록하면 거래처별 미수금이 자동 계산됩니다. 영수증·입금표·잔액 확인서도 인쇄·메일로 보냅니다.

재고 · 거래처별 단가

매입·판매로 소모품 재고가 자동으로 늘고 줄며 부족하면 알려 줍니다. 거래처마다 정한 단가가 전표에 자동으로 들어갑니다.

통계 · 일계표 · 국세청 조회

월별 매출 차트와 거래처·품목 순위, 일계표·월계표. 거래처 사업자번호 오류와 휴업·폐업을 국세청에서 확인합니다.

네트워크 공유 · 자동 백업

같은 사무실의 다른 PC·휴대폰에서도 접속할 수 있고, 매일 자동 백업되며 언제든 복원합니다.

가격

출시 기념 특가 진행 중 — 한정 기간 동안 연간·평생 라이선스를 정가보다 낮은 가격에 드립니다. 종료일은 이 페이지에 공지합니다.

구매 방법

  1. 체험판 설치 — 90일 동안 모든 기능을 써 봅니다.
  2. 구매 문의 — 전화 031-433-2480 또는 nuri@sindoida.co.kr 로 연간·평생 중 원하는 방식과 PC 고유번호([환경설정 → 라이선스]에서 확인)를 알려 주세요.
  3. 결제 — 계좌이체 후 세금계산서를 발행해 드립니다.
  4. 라이선스 키 등록 — 입금 확인 후 키를 보내 드립니다. 프로그램에 등록하면 바로 정식 사용이 됩니다. (인터넷 없이 등록)

설치 방법

  1. 내려받기 — 위의 [무료 체험판 내려받기]를 눌러 OA_Rental_Setup.exe를 받습니다.
  2. 설치 실행 — 받은 파일을 실행합니다. Windows 보안 경고가 나오면 [추가 정보] → [실행]을 누릅니다.
  3. 처음 설정 — 설치가 끝나면 브라우저가 열립니다. 회사명과 로그인 아이디·비밀번호를 정하면 바로 사용할 수 있습니다.
  4. 다른 PC에서 접속(선택) — [환경설정 → 네트워크 공유]에서 허용하면 같은 사무실의 다른 PC에서 접속할 수 있습니다.

새 버전도 같은 방법으로 설치하면 되며, 입력한 자료(C:\ProgramData\OARental)는 그대로 유지됩니다.

개선내용

버전별 개선내용
※ [OA 렌탈관리] 1.4.0 버전 개선내용 (2026.11)
  • 견적서 양식 개편 — 공급자 화면을 따로 두고, 받는자의 회사명·담당자만 입력하면 바로 품목을 입력해 한 장으로 작성됩니다. 공급자 화면에서도 공급받는자가 위쪽에 먼저 보입니다.
  • 견적서 카카오톡 PDF 보내기 — 견적서를 PDF 파일로 만들어 카카오톡 '나에게 보내기'로 전달할 수 있습니다.
  • 거래명세 분리·합치기 — 같은 거래처에 따로 등록한 판매는 거래명세표가 각각 발행되고, 수정에서 품목을 추가하면 하나의 거래명세표로 합쳐집니다. 같은 날 판매한 세금계산서는 기본으로 합쳐 발행합니다.
  • 직전 판매단가 자동 입력 — 판매등록에서 품목을 고르면 그 거래처에 마지막으로 판매한 단가가 판매단가에 자동으로 들어갑니다.
  • 복사 버튼 추가 — 환경설정의 네트워크 공유(접속 주소)와 계정·API 키 화면에서 주소와 키를 버튼 한 번으로 복사합니다.
※ [OA 렌탈관리] 1.3.0 버전 개선내용 (2026.11)
  • 매입 계산서 불러오기 — 홈택스에서 내려받은 매입 세금계산서 엑셀 또는 바로빌 연동으로 매입 전표를 자동 생성합니다. 손으로 입력해 둔 매입은 승인번호만 연결하고, 같은 계산서는 두 번 만들지 않습니다. 월 합계 계산서와 품목별 수기 매입이 이중으로 잡히지 않게 직접 묶는 기능도 있습니다.
  • 이전 시점으로 복원 — 매일 자동으로, 그리고 자동 불러오기 직전에 데이터를 저장해 두고, 날짜를 골라 그 시점으로 되돌립니다. 복원 직전 상태도 따로 저장되어 다시 돌아올 수 있습니다. (환경설정 메뉴)
  • 견적서 개선 — 직인 표시, 비교 견적, 품목별 상세 사양, 미등록 품목을 품목마스터에 바로 등록, 입금계좌·합계금액 표시 선택, 하단 업체 설명·유효기간 문구, PDF 저장 시 파일명을 거래처 상호로 자동 입력
  • 지급 등록 일별 매입 조회 — 매입처의 월별 매입에서 "일별"을 누르면 그 달의 일자별 매입금액이 나와 지급일을 정하기 쉽습니다.
