견적서부터 거래명세서,
미수금까지 PC 한 대로

견적 확정 한 번에 거래명세서가 채워지고, PDF를 첨부해 바로 메일로 보냅니다. 인터넷 없이 내 PC에서 빠르게 동작합니다.

무료 체험판 내려받기 설치 방법
Windows 10 / 11 · 30일 무료 체험 · 게시자 신도OA디지털

주요 기능

견적서 → 거래명세서

견적이 확정되면 버튼 하나로 내용이 채워진 거래명세서 작성. 날짜·단가만 고쳐 저장합니다.

A4 양식 인쇄 · PDF 메일

전용 용지 없이 일반 A4에 양식째 인쇄. PDF를 자동 첨부해 거래처에 바로 발송합니다.

발주 · 입고 · 재고

발주서에서 입고 명세서로 넘기면 재고가 자동으로 늘어납니다.

입금 · 미수금

입금을 등록하면 거래처별 미수금이 자동 계산됩니다.

매출·매입장 / 부가세

홈택스 세금계산서 발행 기록을 남기고, 1기·2기·분기별 예상 부가세와 미기록 건을 확인합니다.

영업일지 · 자동 백업

상담 기록과 다음 연락일 알림. 날짜별 자동 백업으로 며칠 전 자료로도 되돌릴 수 있습니다.

설치 방법

  1. 내려받기 — 위의 [무료 체험판 내려받기]를 눌러 HansungForm.zip을 받습니다.
  2. 압축 풀기 — 받은 파일을 마우스 오른쪽 클릭 → [압축 풀기].
  3. install.bat 실행 — Windows 보안 경고가 나오면 [추가 정보] → [실행]을 누릅니다.
  4. 시작 — 바탕화면의 "한성폼" 바로가기로 실행하고 비밀번호를 정하면 바로 사용할 수 있습니다.

새 버전도 같은 방법으로 설치하면 되며, 입력한 자료(C:\한성폼\data)는 그대로 유지됩니다.

사용 기간 · 라이선스

무료 체험설치 후 30일, 모든 기능 사용
정식 사용라이선스 키를 구입해 프로그램의 [라이선스] 메뉴에 등록 (사업자번호 기준 발급)
