누리

Home > 다운로드 > 누리

기능 제한 없이 3개월까지 무료로 이용할 수 있습니다.

누리는 거래처·품목, 견적서, 판매·매입, 수금·미수금, 매출·매입장과 부가세 요약까지 한 번에 관리하는 PC용 통합 관리 프로그램입니다. 설치 후 3개월 동안 모든 기능을 그대로 써 보시고, 합리적인 비용으로 유지보수를 받으실 수 있습니다.

유지보수 비용 — 1년 / 30,000원 (부가세 별도) ※ 무료 사용 기간 중에도 언제든 유지보수 회원으로 바꿀 수 있으며, 입력한 자료는 그대로 이어서 사용합니다.

  • 설치하면 바로 3개월 무료 사용이 시작됩니다. 회원가입은 필요 없습니다.
  • 3개월이 지난 뒤 계속 쓰시려면 전화(031-433-2480)나 이메일로 유지보수를 신청하세요. 결제 후 등록 키를 보내 드립니다.
  • 사무실 여러 PC에서 하나의 장부를 함께 쓸 수 있습니다. 여러 PC에서 쓰실 때의 비용은 전화로 문의해 주세요.
  • 입력한 자료는 사무실 PC에만 저장되고 인터넷으로 나가지 않습니다.
  • 허락 없이 재판매·배포하는 등 상업적인 목적으로 이용할 수 없습니다.
※ 아래의 프로그램을 내려받아 설치하는 것은 위 사항에 동의하는 것으로 봅니다.

설치 방법

  1. 위의 누리 다운로드를 눌러 설치 파일 Nuri_Setup.exe를 내려받습니다.
  2. 받은 파일을 실행합니다.
    “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행을 누르세요. (새로 나온 프로그램이라 처음 한 번 나오는 안내입니다)
  3. 설치 화면에서 다음을 눌러 진행합니다. C:\Nuri 폴더에 자동으로 설치되고, 바탕 화면과 시작 메뉴에 누리 아이콘이 만들어집니다.
  4. 처음 실행하면 회사 정보·백업 메뉴에서 상호·사업자번호를 입력하세요. 견적서와 거래명세표에 인쇄됩니다.

새 버전으로 바꿀 때: 새 설치 파일을 받아 그대로 실행하면 됩니다. 입력한 자료는 따로 저장되어 그대로 남습니다.
지울 때: Windows 설정 → 앱 → 누리 → 제거. (자료는 남아 있어 다시 설치하면 이어서 쓸 수 있습니다)
